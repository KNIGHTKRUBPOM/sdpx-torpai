# PairEval Wireframes

Wireframes ชุดนี้ revise ตาม PairEval PRD และ backlog Sprint 1 โดยใช้ mobile-first flow และวางองค์ประกอบที่จะอ้างด้วย accessible role/label ใน E2E test

1. [`screen1_instructor_dashboard.excalidraw`](screen1_instructor_dashboard.excalidraw) — assignment status, participation, coverage และ CTA สร้าง assignment
2. [`screen2_assignment_setup.excalidraw`](screen2_assignment_setup.excalidraw) — artifact, score split, criteria weights, feasibility preview และ publish
3. [`screen3_student_evaluation.excalidraw`](screen3_student_evaluation.excalidraw) — pair artifacts, six labelled choices, progress, autosave status และ submit

ผลชั่วคราวของนักศึกษาถูกรวมใน evaluation flow หลัง submit เพื่อไม่เพิ่ม screen ที่ไม่จำเป็นใน M1 และต้องไม่แสดง evaluator identity หรือ score delta ตาม FR-ANON-01/03
