# Present: Performance & Observability

## เวลา: 1 ชั่วโมง (6 กลุ่ม × 10 นาที)
## รูปแบบ: อาจารย์ random 1 คนจากกลุ่ม

## 🎯 การ present นี้ฝึกอะไร

| สิ่งที่จะทำได้ | ใช้ในงานจริงอย่างไร |
|---|---|
| เล่าว่าเดาผิดตรงไหนและเรียนรู้อะไร | วัฒนธรรมที่ยอมรับการเดาผิดอย่างเปิดเผยคือวัฒนธรรมที่ทีมเก่งขึ้นเร็ว |
| แปลตัวเลข p95 เป็นผลกระทบต่อผู้ใช้ | ทำให้คุยกับคนนอกสายเทคนิคได้รู้เรื่อง |
| ชี้ bottleneck พร้อมหลักฐาน ไม่ใช่ความรู้สึก | เป็นวิธีเสนอแผนแก้ที่ทำให้คนอื่นเชื่อและอนุมัติ |
| ตรวจสอบว่ามีข้อมูลอะไรใน log ที่ไม่ควรอยู่ตรงนั้น | เป็นสิ่งที่ privacy review จะถามเป็นข้อแรก |

---

## สิ่งที่ต้อง Present (10 นาที/กลุ่ม)

### Demo (5 นาที)
1. รัน k6 test ให้เห็นผลใน terminal
2. ชี้ค่า p95, error rate, throughput และอธิบายว่าแต่ละตัวหมายถึงอะไรกับ user จริง
3. เปรียบเทียบกับ hypothesis ที่ส่งมา — ถูกหรือผิด และเรียนรู้อะไร
4. แสดง structured log 1 บรรทัด (ผ่าน `jq`) และชี้ `requestId`, `duration_ms`
5. แสดงว่า threshold ที่ไม่ผ่านทำให้ CI job แดงจริง

### คำถาม (5 นาที)
อาจารย์อาจถาม:
- "p95=500ms ดีหรือแย่สำหรับ feature นี้ ตอบจากมุมของ user"
- "Hypothesis ที่ผิดเพราะอะไร เรียนรู้อะไรจากการผิด"
- "ถ้าจะแก้ bottleneck นี้จะเริ่มจากตรงไหน และจะรู้ได้ยังไงว่าแก้แล้วดีขึ้นจริง"
- "Structured logging ช่วยอะไรที่ `console.log` ทำไม่ได้"
- "ใน log ของกลุ่มมีข้อมูลอะไรที่ไม่ควรอยู่ตรงนั้นไหม"
- "AI เสนอสาเหตุอะไร กลุ่มไม่รับข้อไหน เพราะอะไร"

## Rubric (5 คะแนน)

| เกณฑ์ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **k6 Test Quality** | แค่ hit homepage | หลาย endpoints | realistic journey + think time | + thresholds + tags | + stages + custom metrics + ทดสอบแล้วว่า gate แดงได้จริง |
| **Analysis** | copy output เฉย ๆ | อ่านค่าได้ | อธิบาย p95 ได้ | ระบุ bottleneck + หลักฐาน | + แนวทางแก้ที่ specific + วิธียืนยันผล |
| **Hypothesis** | ไม่มี | มีแต่ไม่เชื่อมผล | เชื่อมได้บางส่วน | ถูก/ผิด + เหตุผล | + เรียนรู้จากการผิดอย่างชัดเจน |
| **Observability** | console.log | มีแต่ text | JSON format | + requestId + duration_ms | + redact ข้อมูลอ่อนไหว + ใช้ route pattern |
| **AI Judgement** | ไม่ได้ใช้/รับทุกอย่าง | ใช้แต่ไม่มีข้อมูลป้อน | ป้อนข้อมูลจริงให้ AI | + คัดรับ/ไม่รับพร้อมเหตุผล | + ระบุได้ว่า AI ไม่รู้ context อะไรของระบบเรา |

**คะแนนเต็ม: 5 คะแนน** (เฉลี่ยจาก 5 เกณฑ์)
